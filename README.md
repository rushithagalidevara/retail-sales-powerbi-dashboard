# Retail Sales Power BI Dashboard

Interactive Power BI dashboard analyzing retail sales performance — profitability, customer segments, regional trends, and top-performing products — built on the Sample Superstore dataset (9,994 line items, 5,009 orders).

## Key Insights

| Metric | Value |
|---|---|
| Total sales | $2,297,201 |
| Total profit | $286,397 (12.5% margin) |
| Orders | 5,009 |
| Avg. discount | 15.6% |

- **Technology** led both sales ($836K) and profit ($145K, 17.4% margin) — the strongest category on both dimensions.
- **Furniture** nearly matched Office Supplies on sales ($742K) but returned only $18K in profit (2.5% margin) — heavy discounting is eroding furniture profitability.
- **Tables** was the single biggest profit drag in the entire dataset, losing **-$17,725** despite solid sales volume.
- **West** was the top-selling region ($725K); **Consumer** was the top-selling segment ($1.16M, >50% of total sales); **California** and **New York** were the top two states.

## Dashboard Features

- KPI cards for Sales, Profit, Orders, and Discounts
- Monthly sales trend analysis
- Profit by category
- Sales by region
- Customer segment analysis
- Top product analysis
- Interactive slicers and filters
